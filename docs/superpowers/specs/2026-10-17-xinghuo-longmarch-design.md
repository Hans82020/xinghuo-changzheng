# 《星火长征》设计文档

- **日期**：2026-10-17
- **状态**：已与需求方逐节确认，待最终评审
- **项目路径**：`d:\work\mini-games`
- **定位**：以长征党史为文本基础的寓教于乐像素风网页游戏，面向成人党史学习场景

---

## 1. 背景与目标

制作一款像素风格的党史教育小游戏，以中央红军长征（1934.10 于都出发 → 1936.10 会宁会师）为叙事主线，让玩家在"行军 + 决策 + 问答 + 专属玩法"的循环中记住关键史实与经典故事。

**成功标准**：

- 成人玩家完整玩一局（约 30~50 分钟）后，能复述主要节点的关键史实与情感故事；
- 单 HTML 文件双击即玩（`file://` 协议可用，零外部依赖）；
- 核心代码不做结构性改动即可迁移至微信小游戏。

## 2. 已确认的关键决策

| 决策点 | 结论 | 备注 |
|---|---|---|
| 玩法形式 | 俯视行军地图 RPG（方案 B） | 沿固定路线行进 + 节点事件，非开放世界 |
| 目标受众 | 成人党史学习 | 史实细节严谨充实，问答偏中等难度 |
| 内容规模 | 完整细分 14 节点 | 覆盖全程；后续可扩展 |
| 技术方案 | 单文件 HTML + 原生 Canvas + 原生 JS | 零依赖；Phaser/Godot 方案已否决 |
| 失败机制 | 兵力/士气归零后**自选已解锁节点**重开 | 无硬 Game Over |
| 玩法广度 | **每个节点一个专属小玩法**（14 个） | 玩法机制呼应史实，增强记忆 |
| 情感层 | 每节点一个**情感触点**（经典长征故事） | 真实史实优先；教材文学篇目需标注区分 |
| 游戏名 | 《星火长征》，副标题"二万五千里行军记" | 暂定，可更换 |

## 3. 玩法循环

### 3.1 单节点循环（约 2~4 分钟一站）

```
行军段 ──→ 抵达节点 ──→ 史实剧情卡 ──→ 战略抉择/问答 ──→ 专属玩法 ──→ 资源结算
(俯视地图   (触发图文卡   (像素插画+严谨   (1 个二/三选一    (10~30 秒      (兵力/粮草/士气/
 徒步行进，  剧情与史实)   史实，含关键数字) 决策 + 2~3 道    微操作，机制    民心变动 + 收录
 随机小事件)               答错必给史实解析)  史实选择题)      呼应节点史实)   「党史笔记」图鉴)
```

- **行军段**：俯视像素地图，队伍沿路线段行进（方向键/点击目标点/触屏拖动），途中随机触发小事件（敌机侦察、老乡送粮、战士掉队、宣传标兵等），几秒一个轻决策。
- **史实剧情卡**：面向成人的严谨内容——时间、番号、关键数字（如湘江"8.6 万→3 万余"、泸定桥"一昼夜 240 里"）。
- **抉择与问答**：选错不死档，扣资源并给史实解析；答对恢复士气。
- **结算**：资源变动播报 + 本节点党史笔记卡收进图鉴。

### 3.2 失败与重开

- 兵力归零或士气归零 → 进入「重整旗鼓」界面：**玩家自选任意已解锁节点**重开，重开后四项资源恢复为"按标准进度走到该节点入口时的推算值"（由节点表预置数据定义，保证每个入口资源状态一致、可复现）。
- 教育向优先，不做硬性 Game Over。

### 3.3 通关结算

抵达会宁会师后输出通关报告单：行军用时、答题正确率、玩法表现评级、笔记收集度、最终兵力与出发兵力对比、一句长征精神结语。报告单可截图分享。

## 6. 界面结构

逻辑分辨率 320×180（16:9），整体放大渲染（`image-rendering: pixelated`），letterbox 适配不同屏幕。

```
┌──────────────────────────────────────────┐
│ 兵力86,000  粮草100  士气80  民心50 [图鉴][存档] │ ← 顶栏
│                                          │
│          俯视像素地图 + 小队精灵            │ ← 主视图
│          🚩 节点旗帜沿路线排布              │
│                                          │
│ 当前目标：向湘江行进…      [剧情/问答弹层]    │ ← 信息条/弹层
└──────────────────────────────────────────┘
```

弹层四类：剧情卡、问答卡、玩法层、结算卡。UI 文案全部中文。

## 7. 像素美术与音频

- **调色板**：约 32 色复古红金主题——夜行军深蓝 `#1a2332`、旗红 `#e74c3c`、赤水红 `#c0392b`、星火金 `#f1c40f`、草地土黄、雪山冷白、黄土高原赭石。
- **场景地理推进**：江南水乡 → 黔北山地 → 川西雪原 → 松潘草地 → 黄土高原，瓦片风格随节点段切换。
- **精灵**：红军小队 16×16（灰军装、八角帽红五星、绑腿），节点旗帜 16×24；全部代码内嵌像素数据绘制，零外部图片。
- **特效**：雪夜火把光晕、赤水浪花、草地雨丝等轻粒子。
- **文字**：系统字体 + 像素描边阴影（保持零依赖；后续可选 OFL 开源像素中文字体升级，如 Fusion Pixel Font）。
- **音频**：WebAudio 合成 8-bit 音效（行军鼓点、答对小号、会师凯歌），无 BGM，无版权负担。
- **交互**：键鼠（方向键 / WASD / 点击）+ 触屏双支持；所有按钮可点按。

## 8. 技术架构

单文件 `index.html`，内部严格分层：

```
index.html
├── platform/  平台适配层   输入、存档、音频三接口；浏览器实现（localStorage / WebAudio / 键鼠触摸）
├── data/      数据层       14 节点史实文案、题库、事件表、调色板、精灵像素数据（纯 JS 数据）
├── engine/    引擎层       主循环、场景管理、Canvas 渲染、粒子、8-bit 音效合成
├── minigames/ 玩法层       14 个小玩法，统一接口
└── ui/        界面层       顶栏、剧情卡、问答卡、结算卡、党史笔记图鉴
```

**关键约束**：

1. **玩法统一接口**：每个小玩法实现 `init / update(dt) / draw(ctx) / onInput(e)`，以回调返回结算结果（资源变动），主循环只认接口——新增/替换小玩法不动引擎。
2. **禁用 DOM API**：所有画面走 Canvas 绘制（文字用 `ctx.fillText`），核心代码可在微信小游戏的纯 Canvas 环境直接运行。
3. **数据与逻辑分离**：史实内容全部为数据，改文案/加节点不改代码。

**错误处理**：

- 存档带版本号校验，坏档降级为提示后重开，不崩溃；
- 音频遵守浏览器自动播放策略（首次用户交互后才初始化 AudioContext）；
- Canvas 缩放采用整数倍优先 + letterbox，避免像素撕裂。

## 9. 存档与调试

- **自动存档**：每节点完成时保存（资源 + 图鉴 + 进度）；另有手动存档按钮。
- **调试模式**：URL 参数 `?debug=1` 可跳转任意节点、锁定资源，便于验收。
- **微信迁移**：存档接口换成 `wx.setStorageSync`，仅动 platform 层。

## 10. 微信小游戏迁移路径

1. 现阶段即保证：纯 Canvas 绘制、无 DOM 依赖、平台三接口（输入/存档/音频）抽象。
2. 迁移步骤：新建微信小游戏工程 → 引入同一份引擎/数据/玩法代码 → 替换 platform 层（`wx.createCanvas`、触摸事件、`wx.setStorageSync`）→ 适配分包与性能。
3. 上线注意：需注册微信小游戏主体；党史教育类内容正面，但需关注平台内容与资质审核要求。
